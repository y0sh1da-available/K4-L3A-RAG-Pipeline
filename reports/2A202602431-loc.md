## Quyết định kỹ thuật quan trọng

Mô tả tối đa hai quyết định mà bạn trực tiếp tham gia:

1. **Quyết định:**  Chuyển đổi phương thức crawl bài viết ở Task 2 từ việc phụ thuộc vào Playwright Chromium mặc định sang cấu hình executable_path trỏ trực tiếp tới Google Chrome có sẵn trên hệ thống
   **Lý do/evidence:**  Quá trình khởi chạy Crawl4AI liên tục thất bại do thiếu binary chrome.exe trong thư mục Playwright của môi trường Windows (launch_persistent_context không tìm thấy driver).
   **Trade-off:**Code phụ thuộc vào đường dẫn tuyệt đối của Google Chrome trên máy Windows local; nếu đem sang môi trường khác (Linux/Docker) sẽ cần cập nhật lại đường dẫn cấu hình hoặc biến môi trường.

2. **Quyết định:**  Thêm hàm lọc rác clean_pdf_junk và kiểm tra Content-Type kết hợp logic Idempotency ở Task 3 
   **Lý do/evidence:**  Khi tải các link PDF từ trang xem online (viewer.php), file thu được bản chất là HTML Viewer. Khi chuyển đổi bằng MarkItDown, dữ liệu bị dính hàng loạt văn bản rác của giao diện đọc sách (nút Print, Zoom, Rotate, Password...).
   **Trade-off:**Tăng độ phức tạp của code (phải duyệt kiểm tra danh sách keyword rác và trạng thái file tồn tại), đồng thời nếu danh sách keyword chưa bao phủ hết thì vẫn có thể sót rác nhẹ từ các PDF Viewer lạ.
